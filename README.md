# 복도에서 또 마주쳤다

회사 복도에서 같은 동료를 하루에 몇 번씩 마주칠 때의 어색함을 다룬 80초짜리 내레이션 모션 영상입니다.
영상 파일이 아니라 브라우저에서 실시간으로 재생되는 HTML/CSS/JS 페이지입니다.

▶ **재생: https://sandboxwork.github.io/hallway-again/**

- 재생 화면에서 **전체화면으로 재생**(Enter)을 누르세요. Space 재생/일시정지 · ←/→ 이동 · R 처음부터 · C 자막 · D 디버그 바
- 구성: `index.html`(장면) · `css/style.css` · `js/scenes.js`(GSAP 타임라인) · `js/cues.js`(내레이션 타이밍) · `audio/`(내레이션)
- 기획: [`storyboard.md`](storyboard.md) · 대본: [`script.json`](script.json)

사용한 것: [GSAP](https://gsap.com) (Standard License), [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL 1.1), 내레이션 [Fish Audio](https://fish.audio) TTS.
